## 🇬🇧 English

**Cash Converter** is a lightweight, mobile-friendly currency converter built with plain HTML, CSS, and JavaScript. Its visual style combines translucent glass panels, soft gradients, and subtle motion.

### Features
- **Exchange rates online** from the public ExchangeRate-API endpoint.
- **Wide currency selection** based on the currencies returned by the API.
- **Instant conversion** as you type.
- **One-tap swap** to reverse currencies.
- **Quick amount presets** for common values.
- **Copy result** to your clipboard when browser permissions allow it.
- **Responsive interface** for desktop and mobile.
- **No framework or build step** required.

### Run locally
1. Clone the repository:
   `git clone https://github.com/German-GPD/Cash-Converter.git`
2. Open the project folder.
3. Open `index.html` in a modern browser or use a local static server.

### Data and accuracy
Rates are provided by [ExchangeRate-API](https://www.exchangerate-api.com/). The app shows the provider's last-update date when available. Rates can be delayed and are for informational use; they may differ from bank, card, or cash-exchange rates. An internet connection is required.

### Tech stack
HTML5 · CSS3 · Vanilla JavaScript · Fetch API · Intl · Clipboard API · GitHub Pages

## 🇷🇺 Русский

**Cash Converter** — лёгкий адаптивный конвертер валют на HTML, CSS и JavaScript. Дизайн в стиле Premium Glass: полупрозрачные панели, мягкие градиенты и аккуратные эффекты.

### Возможности
- **Курсы валют онлайн** из публичного API ExchangeRate-API.
- **Выбор валют** из списка, который возвращает API.
- **Мгновенный пересчёт** при вводе суммы.
- **Обмен валют местами** одной кнопкой.
- **Быстрый выбор суммы** для популярных значений.
- **Копирование результата** в буфер обмена, если браузер разрешает это.
- **Адаптация под телефон и компьютер.**
- **Без фреймворков и сборки** — обычный статический сайт.

### Как запустить
1. Склонируй репозиторий:
   `git clone https://github.com/German-GPD/Cash-Converter.git`
2. Открой папку проекта.
3. Открой `index.html` в современном браузере или запусти локальный статический сервер.

### Курсы и точность
Курсы предоставляет [ExchangeRate-API](https://www.exchangerate-api.com/). Если источник передаёт дату последнего обновления, приложение показывает её. Курсы могут обновляться с задержкой и предназначены для ознакомления: значения могут отличаться от банковских, карточных и обменных курсов. Для загрузки данных нужен интернет.

### Технологии
HTML5 · CSS3 · Vanilla JavaScript · Fetch API · Intl · Clipboard API · GitHub Pages
