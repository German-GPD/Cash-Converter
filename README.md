## 🇬🇧 English

Cash Converter is a lightweight converter for a focused set of assets:

- **Fiat:** USD, EUR, RUB, BYN, PLN, CNY
- **Digital asset:** Bitcoin (BTC)
- **Precious metal:** Gold (XAU, price per troy ounce)

### Features

- Instant conversion while typing.
- Independent source comparison for EUR, PLN, and CNY when both providers return data.
- Separate market quotes for Bitcoin and gold.
- Clear source status, rate freshness information, and a note when rates cannot be cross-checked.
- Quick amount presets, one-tap swap, and copy result.
- Premium iOS-inspired glass interface with crisp, squared-off corners.
- Responsive layout, keyboard focus states, and reduced-motion support.
- No framework, build step, or API key required.

### Data sources

- [ExchangeRate-API Open Access](https://www.exchangerate-api.com/docs/free) — main fiat feed.
- [Frankfurter](https://frankfurter.dev/) — independent cross-check for supported fiat pairs.
- [CoinGecko API](https://docs.coingecko.com/reference/simple-price) — Bitcoin price in USD.
- [Gold-API](https://www.gold-api.com/) — gold price in USD per troy ounce.

**Important:** availability of an independent source depends on that provider and currency pair. The app compares values only when both data points are available; it does not pretend that every asset has been verified by two sources. Rates are indicative, may be delayed, and may differ from bank, card, exchange, or trading prices. Gold is measured in troy ounces. This is not financial advice.

### Run locally

1. Clone the repository:
   `git clone https://github.com/German-GPD/Cash-Converter.git`
2. Open `index.html` in a modern browser or use a local static server.
3. Internet access is needed for live data.

## 🇷🇺 Русский

Cash Converter — конвертер с фиксированным списком из восьми активов:

- **Валюты:** USD, EUR, RUB, BYN, PLN, CNY
- **Криптовалюта:** Bitcoin (BTC)
- **Металл:** золото (XAU, тройская унция)

### Возможности

- Мгновенный пересчёт во время ввода.
- Независимая сверка EUR, PLN и CNY, если оба источника вернули данные.
- Отдельные рыночные котировки Bitcoin и золота.
- Статус источников, дата курса и понятная отметка, когда сверка недоступна.
- Быстрые суммы, обмен местами и копирование результата.
- Премиальный интерфейс в духе iOS: прозрачное стекло, градиенты и чёткие квадратные формы.
- Адаптация под телефон и компьютер.
- Без фреймворков, сборки и API-ключей.

### Источники данных

- [ExchangeRate-API Open Access](https://www.exchangerate-api.com/docs/free) — основной источник фиатных валют.
- [Frankfurter](https://frankfurter.dev/) — независимая сверка поддерживаемых валютных пар.
- [CoinGecko API](https://docs.coingecko.com/reference/simple-price) — цена Bitcoin в долларах США.
- [Gold-API](https://www.gold-api.com/) — цена золота в долларах США за тройскую унцию.

**Важно:** второй источник доступен не для каждой валюты и каждого актива. Приложение показывает сверку только при наличии двух значений и не выдаёт отсутствие данных за успешную проверку. Курсы справочные, могут обновляться с задержкой и отличаться от банковских, карточных, обменных и биржевых цен. Золото измеряется в тройских унциях. Это не финансовая рекомендация.

### Запуск

1. Склонируй репозиторий:
   `git clone https://github.com/German-GPD/Cash-Converter.git`
2. Открой `index.html` в браузере или используй локальный сервер.
3. Для получения курсов нужен интернет.
